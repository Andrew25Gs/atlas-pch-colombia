# Atlas PCH Colombia · sitio publicado

Versión publicada del Atlas PCH Colombia: un mapa para explorar dónde podría montarse una pequeña central hidroeléctrica (PCH) en los ríos de Colombia. Muestra caudal regionalizado (ENA 2022), salto calculado con FABDEM, sitios candidatos sin solapes y las restricciones de su corredor.

Este repositorio contiene **solo el sitio construido**. El código fuente y el flujo de procesamiento se mantienen en el proyecto original; este repositorio se actualiza con `scripts/publish-github.ps1`.

- Herramienta de **exploración preliminar**: no reemplaza estudios hidrológicos, topográficos, geotécnicos, ambientales ni sociales.
